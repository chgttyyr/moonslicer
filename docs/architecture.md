# MoonSlicer 架构与计算几何算法实现文档

本文档详细阐述 **MoonSlicer**（纯 MoonBit 实现的 3D 打印切片引擎）的核心计算几何算法、数据结构与数学模型。

---

## 1. 核心处理管线 (Slicing Pipeline)

```

| 3D 模型输入 (Binary / ASCII STL)                           |
+-------------------------------------------------------------+
                              |
                              v
+-------------------------------------------------------------+

+-------------------------------------------------------------+
                              |
                              v
+-------------------------------------------------------------+
| 2. 3D 三角面 - 水平截面求交 (slice_mesh_at_z)               |
```

## 2. 数学模型与算法原理

### 2.1 三角形-水平平面求交

给定 3D 三角形空间顶点 $A, B, C$ 与截面高度 $Z = z$。
对于三角形各边 $AB$：
$$P(t) = A + t (B - A), \quad t \in [0, 1]$$
截面交点满足：
$$A_z + t (B_z - A_z) = z \implies t = \frac{z - A_z}{B_z - A_z}$$

- 当 $B_z - A_z = 0$ 时，边与截面平行，无需产生交点；
- 当 $t \in [0, 1]$ 时，交点横纵坐标为 $X = A_x + t(B_x - A_x)$，$Y = A_y + t(B_y - A_y)$；
- 每个有效相交的三角形严格产生 2 个相交点，构成一条 2D 相交线段 $Segment2$。
- 加入 $\epsilon = 10^{-5}$ 的微小扰动以防止截面恰好穿过顶点的退化奇异情况。

### 2.2 拓扑链式缝合（Loop Stitching）

三角形求交得到的线段是空间无序的。MoonSlicer 维护活跃线段链表：
1. 取出首条线段作为当前环的起点；
2. 在剩余候选线段中寻找其终点与当前链末端距离 $< \epsilon$（默认 $10^{-4}$ mm）的邻接线段并追加；若发现反向匹配则自动翻转线段；
3. 直至当前链尾与起点重合（距离 $< \epsilon$），闭合为一个完整多边形；
4. 重复上述步骤直至所有线段均被分配。

### 2.3 面积与绕向（Shoelace Theorem）

封闭多边形顶点序列为 $(x_0, y_0), (x_1, y_1), \dots, (x_{n-1}, y_{n-1})$，有向面积公式为：
$$Area = \frac{1}{2} \sum_{i=0}^{n-1} (x_i y_{i+1} - x_{i+1} y_i)$$
- 若 $Area > 0$，多边形按逆时针（CCW）排列，为**实体外边界**；
- 若 $Area < 0$，多边形按顺时针（CW）排列，为**内部空洞边界**。

### 2.4 多边形角平分线向内偏置（Inward Offsetting）

为了打印指定壁厚（Perimeter Wall Count），需要将轮廓多边形向内部偏置距离 $d = LineWidth$。
对于多边形顶点 $P_i$，其前后两条邻边向量为 $e_1 = P_i - P_{i-1}$ 与 $e_2 = P_{i+1} - P_i$，对应的单位法向量为 $n_1, n_2$。

角平分线方向的偏置顶点 $P'_i$ 计算公式为：
$$P'_i = P_i + d \cdot \frac{n_1 + n_2}{1 + n_1 \cdot n_2}$$

#### 尖角裁剪与自交翻转校验 (Edge Inversion Check)
当多边形局部凹陷或极薄时，向内偏置可能造成多边形自相交或边翻转（崩溃退化）。
MoonSlicer 在生成偏置环后，对每一条偏置边进行向量点积检验：
$$(P'_{i+1} - P'_i) \cdot (P_{i+1} - P_i) \le 0$$
若检测到边向量反转，说明多边形已在该层深偏置下收缩崩溃，算法自动终止并保留上一次有效偏置作为内填充边界。

### 2.5 体积挤出数学建模 (Volumetric Extrusion)

3D 打印机喷嘴挤出的熔融塑料线条并非矩形也非圆形，而是受喷嘴底面平压的**扁平跑道截面（Stadium Cross-section）**：
- 线宽 $W$（Line Width，如 0.40 mm）
- 层高 $H$（Layer Height，如 0.20 mm）
- 截面积由矩形核心与两侧半圆边缘组成：
$$A_{bead} = (W - H) H + \pi \left(\frac{H}{2}\right)^2$$

对于移动距离为 $L$ 的打印路径，挤出的塑料体积为：
$$V = A_{bead} \times L$$

设使用的耗材丝直径为 $D$（标准 $1.75$ mm），截面积为：
$$A_{fil} = \pi \left(\frac{D}{2}\right)^2$$

步进电机驱动耗材推进的长度（G-code 中的 $E$ 增量）为：
$$\Delta E = \frac{V}{A_{fil}} = \frac{A_{bead} \times L}{A_{fil}}$$

## 3. 性能与验证基准

在 MoonBit v0.1.20260920 工具链下，对标准 20mm 校准立方体（12 个三角面，99 层高，双层壁厚，15% 填充）进行完整切片基准测试：
- 内存分配：全流程使用紧凑结构体与数组缓冲区，无垃圾堆积；
- 切片耗时：毫秒级全流程端到端执行；
- 测试覆盖率：包含 14 项完整覆盖几何、STL、切片、偏置、填充、G-code 与 CLI 的自动化测试用例。
