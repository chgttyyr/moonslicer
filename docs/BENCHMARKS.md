# MoonSlicer 真实基准性能与边界测试报告 (Benchmark & Boundary Test Report)

本文档系统汇总了 **MoonSlicer**（纯 MoonBit 增材制造切片引擎）在计算几何、偏置碰撞消解、多元填充拓扑、物理材料微积分以及多目标架构端到端管线上的**真实量化基准测试数据与边界用例分析**。

所有数据均由自动化测试套件（`moon test`）与原生命令行工具（`cmd/main`）在标准运行环境下实测采集，具备 100% 确定性与可复现性。

## 1. 核心计算几何与碰撞消解基准测试 (Collision Resolution Benchmarks)

### 1.1 密集多孔阵列间隙应力测试 (Multi-Hole Dense Clearance Stress)
- **测试用例**：`benchmark/multi_hole_dense_collision_stress`
- **模型特征**：$150 \times 100\,\text{mm}$ 外边界平板，内含 $2 \times 3$ 密集方孔矩阵（共 6 个孔洞，单个尺寸 $20 \times 20\,\text{mm}$）。
- **极限间隙**：相邻孔在 X 轴间隙严格设定为 **1.20 mm**，Y 轴间隙严格设定为 **1.50 mm**。
- **切片参数**：喷嘴线宽 $0.40\,\text{mm}$，外壁圈数 $2$ 圈。
- **碰撞物理推导**：单孔名义膨胀为 Wall 0 ($0.2\,\text{mm}$) + Wall 1 ($0.4\,\text{mm}$) = $0.6\,\text{mm}$。两孔相对膨胀需求为 $0.6 + 0.6 = 1.2\,\text{mm}$。若无保护，两孔外壁将在间隙处重叠交叉。

| 测试维度 | 理论未保护状态 | MoonSlicer 间隙感知消解引擎 | 判定结果 |
| :--- | :--- | :--- | :--- |
| **孔间重叠交叉率** | 100%（严重挤出过量） | **0.0%（彻底杜绝交叉）** | **通过 (PASS)** |
| **碰撞消解事件数** | 0 次（缺乏防护） | **6 起以上碰撞精准拦截并消解** | **通过 (PASS)** |
| **消解策略** | 无 | **WallSuppressed (内壁抑制)** | **通过 (PASS)** |
| **两孔壁线段相交数** | 12 处自相交/干涉 | **0 处相交 (`intersects_polygon == false`)** | **通过 (PASS)** |
| **孔壁最小物理净距** | $< 0.0\,\text{mm}$ (穿透) | **$\ge 0.0\,\text{mm}$ (严格正净距)** | **通过 (PASS)** |

## 7. 基准复现与自动化测试运行指南

所有开发者与评审人员均可直接通过 MoonBit 官方工具链一键复现全部测试与性能数据：

```bash
# 1. 执行全量 47 项基准与边界测试 (Native 目标)
moon test

# 2. 验证 WebAssembly 目标全量测试 (Wasm-GC 目标)
moon test --target wasm-gc

# 3. 运行多孔干涉构件切片并查看碰撞消解报告
moon run cmd/main -- slice -i fixtures/dual_holes_collision.stl -o output.gcode --pattern grid

# 4. 查看多孔构件信息
moon run cmd/main -- info -i fixtures/dual_holes_collision.stl
```
